Why this exists

Everything you need, nothing leaves your laptop

Built to answer one question: can a RAG app be genuinely useful without a cloud bill or a privacy trade-off?

📄

Multi-format ingestion

PDF, DOCX, TXT and CSV — drop in one file or a whole folder in a single session.

💾

Persistent vector store

ChromaDB writes to disk, so you never re-embed the same documents twice between restarts.

🔗

Source citations

Every answer links back to the exact file and page it came from — no black-box answers.

🌐

Opt-in web search

DuckDuckGo search with no API key, blended with local document context in hybrid mode.

🧵

Conversation memory

The last few turns are carried into the prompt, plus a SQLite-backed history that survives restarts.

📝

Paper generator

Turn your retrieved context into IEEE, Elsevier or blog-style DOCX drafts, section by section.

Under the hood

A straightforward, inspectable pipeline

No hidden orchestration — every hop in the chain is a few lines of LangChain you can read in five minutes.

Quick Start

1
Install Ollamacurl -fsSL https://ollama.com/install.sh | sh
2
Pull the modelsollama pull llama3 && ollama pull nomic-embed-text
3
Clone & installgit clone https://github.com/sunilgentyala/local-rag-llm.git && cd local-rag-llm && pip install -r requirements.txt
4
Run itollama serve & streamlit run app.py

Prefer containers? docker compose up spins up Ollama + the app together.

Privacy guarantee

Nothing you upload ever leaves your machine

  • No data is transmitted to any external server.
  • No API key is required to run the core app.
  • All embeddings and inference run on-device via Ollama.
  • Vectors persist locally in .chroma/ (gitignored).
  • Uploaded files are processed via tempfile and deleted after use.
  • Web search is strictly opt-in and clearly labelled in the UI.
