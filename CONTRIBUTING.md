# Contributing

Contributions are welcome.

## Getting started

1. Fork the repo and clone your fork.
2. Follow the [Quick Start](README.md#-quick-start) to get Ollama and the app running locally.
3. Create a branch for your change: `git checkout -b feature/short-description`.

## Guidelines

- Keep changes focused — one feature or fix per pull request.
- Match the existing code style (type hints, small focused functions).
- Update `README.md` or `docs/` if you change behavior that's documented there.
- Test manually against the **Chat**, **Generate**, and **History** tabs before opening a PR.

## Reporting issues

Open a [GitHub issue](https://github.com/sunilgentyala/local-rag-llm/issues) with steps to reproduce, your OS, Python version, and the Ollama model versions in use.
